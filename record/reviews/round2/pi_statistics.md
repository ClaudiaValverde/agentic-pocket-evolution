# Round 2 — External PI + statistics review of DESIGN.md v1
Read: PROMPT.md, DESIGN.md v1 (§12), reviews/round1/{external_pi,statistics}.md, docs/tools_pocket.md (fingerprint 384-d fp16).
Verdict: most round-1 points are in. The estimand still has three gaps that change the numbers: false-positive subtraction, the site-pair unit, and how n_c is obtained. Scope is still about 1.5× what 21 h allows. Changes 1–14 are numbered; cut order is in §3.

## 1. Round-1 points mis-implemented or still open
1. **Null still drawn from the N population (stats A3, partly open).** The per-query null "≥10,000 pockets from non-homologous proteins" *is* the N class. That is acceptable only if (a) the expected null hits are subtracted (change 5) and (b) the covariates of both pockets enter as a conditional model. "Stratified jointly on 4 covariates of both pockets" with 10^4 draws per query is not buildable, because the cells are empty. Fix: change 6.
2. **r_null subtraction dropped (stats A2).** With E < 0.01 per query over |S| ≈ 2.5–3.2 M query sites, about 25–32 k false significant pairs are expected. They fall almost entirely in N and may be of the same order as the true N count, which would inflate F_analog. Fix: change 5.
3. **Hubness / symmetrisation (stats A6) is missing.** Fix: the pair-level rule in change 4, plus a sensitivity run with targets of k-occurrence > p99 removed.
4. **Specificity test still uses "clade-level permutation" (stats E13).** Tips are not exchangeable under descent, so permutation flags phylogenetic signal, not a shift. Fix: change 11.
5. **Sankoff cost-ratio sensitivity (stats D11) dropped.** The design fixes gain:loss at 2:1. Run 1:1, 2:1 and 3:1 and keep only events stable across all three. This is cheap.
6. **"Inverse-clade-size reweighting" is still undefined (stats A5).** Define it as GSC/Henikoff weights per root HOG on the species tree, with pair weight w_i·w_j. Otherwise drop it.
7. **PI #11 is open.** Flag benchmark families (the τ tune half) in the case table, preregister the Leiden resolution (e.g. γ = 1.0, CPM), and report SOG size/split statistics.
8. **PI "PPV not independent of fingerprint training" is open.** Exclude pocketcompare training-set proteins (BioLiP pairs) from the shared-ligand enrichment, or report the enrichment with and without them.
9. **Contamination check is 200 pairs (stats A4 asked 2,000).** 200 is acceptable for time, but report ε with a Wilson CI and give F_analog bounds with "unknown" assigned to each side.

## 2. Estimands (§4.2): define and compute like this
10. **Unit and representative.** The unit is an unordered site pair (i, j) on *different* proteins from tier-1/2 sites S. H0 is excluded. The site fingerprint is the fingerprint of the highest-burrow-score pocket in the site; do not use the max over pocket pairs, which inflates similarity with site size. For H1/H2, split by position: **H1s/H2s** = same SOG (positional homolog) and **H1x/H2x** = homologous proteins but different sites. Only H1s/H2s count as "ancestry of the pocket". H1x/H2x are reported separately as within-family analogy. Tier-2 proteins placed by DIAMOND carry no ortholog/paralog call, so their pairs form a combined class H12 (same root HOG).
4. **Significance (pair-level).** A pair is significant iff max(E_ij, E_ji) < 0.01, i.e. in both directions. This handles hubness.
6. **Null that conditions on both pockets.** Step 1: fit μ(x_i, x_j) and σ(x_i, x_j) by linear/quantile regression of s on both pockets' covariates (volume, burrow score, polar/aromatic fraction, mean pLDDT, model source, AF flag). Fit on 10^6 random N pairs drawn with seed 0. Set z = (s − μ)/σ. Step 2: for each query, compute z against 10^4 random non-homologous targets and fit a GPD to the top 5 %; p_tail gives E = |S|·p. Step 3: check calibration on a *held-out* set of 10^6 random N pairs (seed 1) with a QQ plot of p and the observed count at E < 0.01 against the expected count. The size-only and covariate-only baselines are reported in the same table. Compute cost is 3·10^10 fp16 dot products, which takes minutes on one 4090.
12. **Numerator, exhaustive, not sampled.** K_c = the number of significant pairs in class c, read from the symmetrised kNN k = 1000 lists. Saturation check: any query whose 1000th neighbour still has E < 0.01 is re-run at k = 10^4 (or by range search). Report the saturated fraction; if it is > 1 %, report K_c as a lower bound. Note that the per-pair F needs only K_c, because F_anc = Σ_anc K_c / Σ K_c, so n_c is needed only for the rates r_c.
13. **Denominators n_c and the sampling scheme.**
   - H1/H2/H12: count exactly from HOG membership as Σ over protein pairs of |sites_i|·|sites_j|. H1s/H2s are counted from SOG membership.
   - H3 by joins (Pfam clan / PANTHER / CATH superfamily co-membership): also exact, by counting the products of group sizes minus HOG overlaps.
   - H3 residual (MMseqs2 only), H4 and N: draw a uniform sample of M = 100,000 protein pairs (seed 0), weighted by |sites_i|·|sites_j| and excluding join-classified pairs. Run MMseqs2 (E < 1e-3) and Foldseek TM-align mode (E < 1e-3 or TM ≥ 0.5) on exactly those pairs. Estimate n̂_c = p̂_c·N_rest. At H4 rates of about 0.5–2 %, M = 10^5 gives 500–2,000 positives and a relative SE of ≤ 5 %. n_N = total − Σ others.
   - The same 10^5 sample is the random-N background for the ligand-class enrichment, so no second draw is needed.
5. **Rate with null subtraction.** r̂_c = (K_c − Ê0_c)/n̂_c, where Ê0_c = (observed held-out null rate from change 6) × n̂_c. F_analog uses K_N − Ê0_N. Report both raw and subtracted values.
14. **CI.** Use a two-way pigeonhole bootstrap over root HOGs: 200 replicates (stats A5; 1,000 is unnecessary), with seeds seed·1000 + r. Proteins without a HOG are singleton clusters. In each replicate, recompute K_c and n̂_c jointly, resampling the 10^5 denominator pairs by their HOG weights m_i·m_j. Use percentile CIs, and add Wilson intervals for p̂_c as a check.
   - Weightings: per pair (raw K); per site (each query's significant pairs share weight 1); per family pair (each root-OG × root-OG cell weight 1, split over its pairs).
   - Report F at E ∈ {1e-4, 1e-2, 1} as a sensitivity check. The top-k versions (10/50/200) are descriptive only.
   - F_conv,dir: the denominator is the *testable* significant pairs (G has a SOG with ≥ 2 held-out derived and ≥ 2 sister members). Report the testable fraction; F_conv,dir is not extrapolated to untestable pairs.

## 4. New flaws
11. **Specificity null.** For a D-vs-sister contrast, the null is the distribution of the same statistic (fingerprint PC1–3 mean shift, regressed on volume/pLDDT/source) over *all other* sister-clade pairs of matched node depth (±1 rank) within the same SOG set. This is an empirical BM-like null that needs no model fit. It must also exceed the replicate noise floor (cos p10 0.69). Apply BH at q = 0.05 over the number tested, and report that number.
15. **Tier-2 density inflates H classes for the per-pair F.** Swiss-Prot has many model-organism paralogs. State that per-family F is the headline and per-pair F is descriptive.
16. **Simulation error rates should be stratified.** The §5.1 null should draw emission rates by footprint pLDDT band × site size × source (from §3.3), not by species alone.
17. **Prediction to preregister**: K_N − Ê0_N > 0 even in the toy no-convergence world (Gao–Skolnick). The toy world must show F_conv,dir ≈ 0 at the same time, otherwise the Δ test is not calibrated.
